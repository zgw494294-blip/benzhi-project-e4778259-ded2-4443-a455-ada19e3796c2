# 洞穴测绘归档验收工作台

本项目面向洞穴测绘员、拓扑校审员和成果档案管理员，提供归档包建档、测站测段修订、拓扑质量检查、发现裁决、返修复验、成果冻结及归档验收凭据签发的完整流程。服务内置原生 HTML、CSS 和 JavaScript 工作台，并通过同源 JSON API 驱动业务。

工作台同时支持归档编号/洞穴关键词检索、状态和测绘日期组合筛选、分页状态统计；修订提交提供逗号或制表符表格粘贴、来源行预检、内容去重和原子写入。表格固定使用 `id,name,x,y,z` 测站表头和 `id,from,to,distance,azimuth,inclination` 测段表头，也识别对应中文表头。建档与修订入口使用请求摘要实现安全重试，编号或内容冲突会返回已有资源 ID。质检运行保存输入摘要、规则版本和发现摘要，相同输入会重放原运行，查询时会重新校验一致性。

严重发现的豁免需要不同的二次复核人，整改裁决需要说明与关联对象，批量裁决和完成校审均执行整批门禁。返修详情提供测站测段字段差异和发现追溯；`GET /api/archives/{archiveId}/check-runs/{checkRunId}/comparison` 在摘要验真后输出已解决、仍存在和本次新增发现，并支持 `category`、`severity`、`ruleCode` 筛选。冻结预览包含稳定排序的实体快照、计数、版本及预览摘要，冻结时必须完整匹配。

验收凭据支持幂等签发，并分别校验凭据哈希、冻结清单引用和修订内容摘要。`POST /api/certificates/verify-batch` 接收 `certificateIds` 数组，一次只读核验 1 至 100 个编号，按首次出现顺序去重并返回有效、无效、未找到汇总。总览使用 `GET /api/archives?summary=true` 返回跨归档验收统计及未裁决、待整改、冻结摘要和凭据异常归档 ID。

标准构建、运行与测试：

```text
go build ./...
go run ./cmd/server -addr=127.0.0.1:19473
go test ./...
```

也可使用 `PORT` 环境变量指定端口号；服务始终绑定 `127.0.0.1` 回环地址。`go run ./cmd/server -selfcheck -addr=127.0.0.1:19473` 会启动真实 HTTP 服务并执行有界自检流程。
